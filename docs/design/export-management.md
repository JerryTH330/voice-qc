# 异步导出管理设计

当前阶段：HTML 原型已实施并验证。设计确认：2026-09-21；实施：2026-09-22。

## 已确认

- 录音列表、线索列表、工牌明细的导出请求进入统一的导出管理页面。
- 任务创建后不允许修改或手动中断。
- 仅已完成、失败、已过期的任务允许删除；排队中、导出中不可删除。
- 删除已完成任务时，同时删除其导出文件。
- 提交成功后留在原列表，提示“导出任务已创建”，提供“查看任务”入口。
- 仅展示本人创建的任务，下载和删除也仅限本人。

- 客户聚合视图同步接入，来源区分为录音列表、线索列表、客户聚合列表、工牌明细。
- 导出内容以提交时为准，固定筛选条件、字段顺序和数据范围；页面后续调整不影响原任务。保留 Excel 格式，导出全部匹配记录。
- 导出文件保留 7 天，到期自动清理文件，任务记录保留并显示“已过期”；不可下载，可以删除。
- 失败任务显示失败原因，不提供重试按钮；用户回原列表重新发起。

## 页面与操作

- 左侧“管理”分组新增“导出管理”入口。
- 列表显示文件名称、来源、状态、记录数、提交时间、完成时间、失效时间、操作，按提交时间倒序。
- 支持来源、状态、提交日期筛选，以及文件名搜索。
- 点击任务名称查看详情，展示提交时筛选条件、导出字段和失败原因（失败时）。
- 状态为排队中、导出中、已完成、失败、已过期。
- 文件有效期从导出成功时起算 7 天。
- 完成后站内提示，可点击查看任务，不自动下载。
- 仅支持单条删除，操作前二次确认；排队中、导出中不显示删除操作。

## 交付与实施边界

- 本次交付现有 HTML 原型的完整交互演示，包含四个导出来源、任务状态流转、下载、过期和删除。
- 刷新后保留任务记录；前端模拟不代表关闭浏览器后仍有后台服务持续执行。
- 真实异步执行需要后端任务服务，不属于本次 HTML 原型实施范围。
- 不修改 Vue 项目。用户后续调用 implement 授权实施并提交到当前分支，未授权推送或发布。
- 2026-09-22 用户显式调用 implement，按已发布规格实施。

## 现有行为核对

- 三处目前均在浏览器中直接生成并下载 XLSX，没有异步任务执行与管理能力。
- 导出当前筛选匹配的全部记录，遵循当前字段设置的可见列及顺序。
- 线索页面包含线索视图与客户聚合视图，两者导出内容不同。
- 文件名采用页面名及时间戳。
## 实施与验证

- 四个来源共用任务模块与 IndexedDB 存储，保留提交时内容及生成的 XLSX 字节；当前使用固定演示身份，仅模拟本人可见性。
- 导出成功前不会自动下载；排队约 1 秒后进入导出中，再由前端生成文件。关闭页面时没有后台任务服务，重新打开后前端继续推进。
- 5 项新增任务行为测试通过，全量 20 项 Node 测试通过；JavaScript 语法及 diff 检查通过。
- 本地 HTTP 真实浏览器验收：四来源创建、查看任务、刷新恢复、筛选、搜索、详情、失败原因、过期禁下载、单条删除确认/取消、删除后刷新、他人示例任务不可见。
- 四份实际下载的 XLSX 已核对 ZIP/XML 有效性：录音 1888 行/33 字段、线索 1840 行/31 字段、客户聚合 1821 行/25 字段、工牌明细 470 行/24 字段；均无操作列。
- 成功后 7 天时间边界、下载/删除本人权限、任务内容快照由任务公共接口测试覆盖；失败与过期页面通过独立验收数据页稳定验证。
- Standards 和 Spec 两轴审查复查无剩余发现。
- 尚未验证 file:// 跨页 IndexedDB 持久化；建议通过项目约定的本地 HTTP 服务预览。
- 独立验收页为 tests/export-task-fixtures.html，仅用于本地创建/清理带“验收示例”前缀的记录，不加入业务导航。
