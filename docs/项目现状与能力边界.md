# AI质检项目现状与能力边界

> 文档状态：现状基线  
> 更新时间：2026-07-22  
> 用途：作为新需求对接、产品设计、数据开发和前端开发的共同参考。  
> 说明：本文只记录已经确认的项目事实与口径；原型中的演示数据或尚未开发的方案，不自动视为线上既有能力。

## 1. 产品定位

本系统面向汽车销售过程中的录音质检与客户洞察，核心工作是：

1. 接收线上云外呼录音和线下工牌录音；
2. 对符合条件的录音进行ASR转写；
3. 基于单条录音文本完成SOP质检、客户洞察、话术评价和风险识别；
4. 将录音及分析结果与外部线索、到店、试驾等业务数据关联；
5. 在线索和录音页面展示分析结论，并为后续客群聚合分析提供基础数据。

系统的核心是“充分分析已有录音”。到店率、试驾率、成交率等经营转化指标由其他产品承接，本系统不以建设完整转化漏斗为核心目标。

## 2. 业务阶段与录音来源

### 2.1 云外呼邀约录音

来源为线上承接的云外呼录音，统称为“邀约录音”，包含三个场景：

- 首触跟进；
- 邀请/邀约到店；
- 排程确认。

云外呼侧可以取得线索ID，因此邀约录音可以直接与线索关联。

当前并非所有邀约录音都会进行ASR。现行规则只对30秒及以上录音进行ASR分析，不符合条件的录音仍可能存在录音元数据，但没有文本分析结果。

### 2.2 工牌到店录音

来源为门店工牌录音，统称为“到店录音”，包含两个场景：

- 销售接待；
- 试乘试驾。

只有门店实际上传的录音才可能进入分析。工牌录音不能保证全部关联到线索，因此“没有匹配到到店录音”不能直接解释为“客户没有到店”。

### 2.3 五个录音场景

当前采集和分析范围只包括以上五个场景。新需求不得默认系统还采集了报价、下订、交车、售后等其他独立场景录音，除非后续另行确认。

## 3. 核心领域对象及关系

### 3.1 客户

客户指自然人。现阶段可使用手机号作为跨线索去重标识。一个客户可能对应多条线索，也可能产生多条录音。

### 3.2 线索旅程

线索旅程是客群归属判断的基本单位，表示一条线索从首次邀约沟通到后续到店、试驾及线索状态变化的过程。

已确认规则：先按线索旅程判断客群归属，再在同一客群内部按手机号去重统计。

### 3.3 录音

一条线索可以关联多条录音。每条录音单独保存ASR文本和一份独立分析结果。

### 3.4 线索级结论

系统会在多条录音分析结果的基础上形成一份线索级结论，并在线索列表和线索详情展示。

- 外部线索中的意向等级由业务人员人工判断；
- AI意向由录音分析产生；
- 当前线索级AI意向取最后一条录音的AI意向；
- 人工意向与AI意向是两个独立字段，不应混用。

当前“取最后一条录音”的规则为现行规则，后续可根据产品需要优化，如聚合线索旅程的所有录音进行分析。

### 3.5 业务事实

线索状态包含跟进中、已下订、战败、异地成交等业务描述，但线索状态本身没有统一、明确的到店状态。

到店和试驾事实来自其他业务记录，包括：

- 到店时间：`in_store_time`、`arrived_time`；
- 试驾时间：`td_start_time`、`execute_start_time`；
- 线索关联标识：`dealer_clue_id`、`new_clue_id`。

这些业务记录可以与云外呼录音所使用的线索稳定汇聚到同一条线索，因此后续可以使用业务事件判断真实到店或试驾，不需要用“是否存在工牌录音”代替业务事实。

## 4. 数据关联现状

### 4.1 邀约录音关联

邀约录音直接使用云外呼提供的线索ID，云外呼的录音一定是可以匹配上线索的。

### 4.2 到店录音关联

工牌录音通过日期、手机号、顾问、品牌/门店等字段与到店或试驾业务记录匹配，并在同一规则下选择时间最接近的录音。当前使用的匹配组合包括：

1. 日期＋手机号＋顾问＋品牌/门店；
2. 日期＋顾问＋品牌/门店；
3. 日期＋手机号＋品牌/门店。

只要匹配成功，即可作为本系统的可分析关联结果。已到店的线索不一定可以全部匹配上录音，但是已有录音的绝大部分可以匹配上线索，这是已知数据边界。


## 5. 已跑通的单条录音分析能力

### 5.1 ASR文本

系统展示录音转写文本，并将分析结论与对话证据关联。只有完成ASR的录音才具备文本分析结果。

### 5.2 SOP质检

系统按业务场景检查SOP规则是否命中，并展示：

- 单项规则名称；
- 命中或未命中结果；
- 对应对话证据；
- 单条录音的整体命中情况。

当前已确认的线上线索邀约 SOP 包含 7 项标准动作：

| SOP动作标签 | 核查目标 | 典型语义 |
|---|---|---|
| 确认意向车型 | 明确客户主要关注车型或配置版本 | 询问主要看哪款车型、心仪哪个配置 |
| 确认购车关注点 | 明确客户重点关注的产品能力 | 询问空间、动力、续航、舒适、座舱或智驾需求 |
| 确认对比车型 | 明确客户正在对比的品牌、车型或试驾情况 | 询问其他品牌/车型及竞品试驾情况 |
| 确认增换购情况 | 明确现有车辆及增购/置换计划 | 询问当前车型、增购或置换 |
| 确认计划购车时间 | 明确下单计划和关键用车节点 | 询问预计下单时间及近期用车节点 |
| 提出试乘试驾邀请 | 明确邀请客户到店体验或试驾 | 邀请客户确定时间并说明试驾安排 |
| 提出添加微信邀请 | 建立微信承接并说明发送内容 | 邀请添加微信，发送资料、定位或活动信息 |

现有 SOP 规则只根据销售顾问实际说出的内容判断，支持语义相近表达，并返回单项结果、实际话术证据及整体完成/合格统计。

“完成”和“合格”是两个不同口径：

- 完成：销售实际说出了该项核查或邀请内容；
- 合格：销售已说出，且关键信息满足该项标准要求。

当前规则文本同时要求 `completed_items`、`completion_percentage`、`qualified_items`、`qualified_percentage`。为了支持群体动作洞察，结构化接口需要保证每个 SOP 动作分别提供 `completed`、`qualified` 和 `evidence`，不能只保留一个含义不明确的布尔值。


### 5.3 客户描摹与客户意向

单条录音可以输出：

- 客户描摹；
- 客户意图及证据；
- AI意向等级；
- AI意向车型；
- 建议跟进动作；
- 建议二次跟进时间；
- 客户画像标签。

### 5.4 十三类客户画像标签

当前已经结构化以下13类标签：

| 序号 | 标签类别 | 已确认的典型标签或取值 |
|---|---|---|
| 1 | 抗性点 | 价格敏感、续航担忧、空间不满、配置不满、品牌不信任、金融方案不满、服务不满、对比犹豫、质量担忧、售后担忧、交付周期不满 |
| 2 | 付款方式 | 全款意向、分期意向、首付敏感、利息敏感 |
| 3 | 决策阶段 | 本周决策、本月决策、下月决策、季度内决策、时间未定 |
| 4 | 意向车型 | 根据录音识别具体车型，取值随品牌和车型变化 |
| 5 | 置换情况 | 有旧车待置换、无旧车、旧车已处理、咨询置换政策 |
| 6 | 购车时间 | 根据客户表达识别具体购车时间范围 |
| 7 | 用车人 | 根据客户表达识别车辆主要使用人 |
| 8 | 客户职业 | 根据客户表达识别职业；未识别时为空 |
| 9 | 对比竞品 | 比亚迪、特斯拉、蔚来、小鹏、理想、大众、丰田、本田、其他品牌 |
| 10 | 试驾状态 | 已试驾、未试驾、拒绝试驾、已约试驾 |
| 11 | 购车场景 | 日常通勤、家庭出行、商务用车、长途自驾、跑网约车 |
| 12 | 需求特征 | 空间大、动力强、省油/省电、安全配置、智能科技、外观好看、性价比高、保值率高、保养便宜、家用合适、跑网约车、接送孩子、后备箱大 |
| 13 | 预算区间 | 10万以下、10-15万、15-20万、20-30万、30万以上 |

客户关注点、邀约难点等群体主题可以根据以上结构化标签组合得到，不要求新增一套独立的自由文本标签。

### 5.5 单条录音话术优势

当前已结构化识别以下10类话术优势：

1. 深度需求挖掘；
2. 本品价值塑造；
3. 竞品差异化对比；
4. 价格异议处理；
5. 版本配置引导；
6. 门店/公司优势塑造；
7. 微信留资承接；
8. 留人稳线索；
9. 到店邀约推进；
10. 承诺与风险边界。

每类优势均可输出固定标签和对本次录音表现的具体说明。

### 5.6 单条录音话术缺陷

当前已结构化识别以下10类话术缺陷：

1. 深度需求挖掘不足；
2. 本品价值塑造不足；
3. 竞品差异化对比不足；
4. 价格异议处理不足；
5. 版本配置引导不清；
6. 门店/公司优势塑造不足；
7. 微信留资承接不足；
8. 留人稳线索不足；
9. 到店邀约推进不足；
10. 承诺与风险边界不足。

每类缺陷均可输出固定标签和对本次录音问题的具体说明。

### 5.7 单条录音风险识别

当前风险识别包括：

- 对客户合理诉求推诿、拒绝处理或消极应对；
- 明显不耐烦、催促或打断客户；
- 辱骂或嘲讽客户；
- 客户明确表达不满后，销售未致歉；
- 与客户争执或发生冲突。

风险结果可以定位到对应录音和对话证据。

## 6. 已有页面承载

### 6.1 录音列表与录音详情

- 每条录音独立展示分析状态和结果；
- 录音详情展示ASR文本、SOP结果、客户描摹、客户意向、13类画像标签、话术优势、话术缺陷、风险及证据。

### 6.2 线索列表与线索详情

- 线索列表支持查看外部线索属性、人工意向和线索状态；
- 线索详情按时间展示该线索关联的多条录音；
- 展示线索级客户意向、客户标签和综合结论；
- 支持从线索下钻到录音及录音详情。
