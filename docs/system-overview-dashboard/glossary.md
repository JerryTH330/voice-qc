# 系统总览页术语表

> 状态：随访谈持续补充

| 术语 | 当前定义 | 注意事项 |
|---|---|---|
| 录音总数 | 筛选周期内系统收到的录音元数据条数 | 包含可能未达到 ASR 条件的录音 |
| 可分析录音 | 满足当前分析前置条件的录音 | 云外呼现行 ASR 条件包含录音时长不少于 30 秒；其他来源条件待确认 |
| ASR完成录音 | 已成功生成转写文本的录音 | 不等同于已经完成全部 AI 分析 |
| 分析完成录音 | 已生成页面所需结构化分析结果的录音 | 具体“完整结果集”待确认 |
| 分析失败录音 | 已进入处理流程但最终失败的录音 | 需要与排队中、处理中分开 |
| 录音关联率 | 成功关联到线索的录音占目标录音的比例 | 云外呼与工牌来源的先天关联能力不同，应分来源展示 |
| 已接入门店 | 已完成系统接入或配置、理论上可以产生录音数据的门店 | 当前没有独立主数据，页面无法准确展示 |
| 使用门店 | 筛选周期内至少有 1 条归属该门店的录音完成 AI 分析的门店 | 已确认；无门店归属录音不计入 |
| 已接入销售顾问 | 已建立人员身份或录音归属关系的销售顾问 | 当前没有独立主数据，页面无法准确展示 |
| 使用销售顾问 | 筛选周期内至少有 1 条归属该顾问的录音完成 AI 分析的销售顾问 | 已确认；无顾问归属录音不计入 |
| 门店活跃率 | 使用门店数 ÷ 已接入门店数 | 当前无法取得可靠分母，页面不展示 |
| 顾问活跃率 | 使用销售顾问数 ÷ 已接入销售顾问数 | 当前无法取得可靠分母，页面不展示 |
| 推广目标完成率 | 实际接入或使用数量 ÷ 明确推广目标数量 | 当前没有明确推广目标，页面不展示该指标 |
| 整体覆盖率 | 已覆盖对象数 ÷ 全部应覆盖对象数 | 当前缺少完整总盘子，不应使用这一名称代替活跃率 |
| 人工质检提升率 | AI 质检覆盖或效率相对上线前人工质检的变化 | 当前没有人工质检基线，页面不展示 |
| SOP质检合格录音数 | 所选周期内已完成 SOP 质检且达到合格标准的录音条数 | 分母应使用已完成且适用 SOP 质检的录音，不能直接使用全部录音 |
| SOP质检合格率 | SOP 质检合格录音数 ÷ 已完成且适用 SOP 质检的录音数 | 建议与合格录音数同时展示 |
| 风险录音数 | 所选周期内命中至少一项风险规则的去重录音条数 | 一条录音命中多个风险仍只计算一次 |
| 风险录音率 | 风险录音数 ÷ 已完成风险识别的录音数 | 建议与风险录音数同时展示 |
| 累计指标 | 从项目开始至所选周期末、根据历史录音反推的累计使用和分析规模 | 不能解释为全部已接入对象 |
| 周期指标 | 所选月份或季度内发生的使用和分析结果 | 用于使用门店、使用顾问、录音分析、质检和风险趋势 |
