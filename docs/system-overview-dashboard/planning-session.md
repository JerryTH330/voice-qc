# 系统总览页规划访谈

> 状态：访谈完成，已形成 V1.0 设计文档  
> 创建日期：2026-07-22

## 已确认背景

- 系统面向汽车销售过程中的录音质检与客户洞察。
- 已有厂端看板、门店看板和销售看板，分别承载组织质检、门店管理和个人执行视角。
- 新页面第一使用者已确认为高层管理者，页面定位调整为“AI 质检项目价值总览”。目标不是指导用户分析具体问题，而是用少量指标说明项目建成了什么、覆盖了谁、形成了哪些管理能力，以及是否值得继续推广和投入。
- 经营转化指标由其他产品承接，本页不默认建设完整的到店、试驾、成交漏斗。

## 当前领域模型

```text
录音来源（云外呼 / 工牌）
  -> 录音（五个业务场景）
    -> ASR任务与文本
      -> 单条录音分析结果（SOP / 画像 / 话术 / 风险）
        -> 线索级结论
          -> 现有业务页面与角色看板
```

## 候选信息层级（待访谈确认）

1. 项目落地：多少门店和销售顾问实际产生了 AI 分析结果，覆盖了哪些业务场景。
2. 实际使用：多少门店和顾问在周期内真实产生 AI 分析结果，累计沉淀多少录音与客户数据资产。
3. 管理可见性：过去依赖抽查或无法规模化识别的 SOP、话术、风险和客户信号，现在有多大范围可以被自动识别。
4. 管理结果摘要：只展示整体质检合格、风险和覆盖趋势，不在本页解释具体原因。
5. 能力入口：高层需要进一步追问时，再进入客户洞察、厂端看板、门店看板或录音证据。

## 当前首要问题

访谈已完成。完整页面结构、指标口径、交互和实施步骤见 `full-design-v1.0.md`。

## 已确认汇报主线

页面采用“项目落地 + 管理可见性”的双层叙事：

1. 先说明有多少门店和销售顾问实际使用系统，以及沉淀了多少可分析数据。
2. 再说明系统让多大范围的销售过程从“不可见、靠抽查”变成“可识别、可追溯”。
3. 只给出整体管理结果摘要；具体问题、原因和改进动作交由客户洞察及角色看板承接。

## 与其他页面的边界

| 页面 | 核心问题 | 应展示 | 不应成为核心 |
|---|---|---|---|
| AI 质检项目价值总览 | 项目是否落地、覆盖多广、形成了什么管理价值 | 门店/顾问覆盖、使用规模、数据资产、自动质检覆盖、整体结果摘要、能力地图 | 客群原因分析、竞品细节、具体销售动作建议、问题排行明细 |
| 客户洞察 | 客户为什么不来或不买，哪些信号和销售动作与结果有关 | 客群画像、阶段原因、销售动作差异、竞品事实、A/B 对比、原声证据 | 项目建设进度、系统推广规模 |
| 厂端/门店/销售看板 | 哪个组织或人员表现如何，应该如何管理和改进 | 质检表现、组织/人员排行、SOP 短板、风险复盘、督办 | 项目整体建设价值汇报 |
| 录音列表与详情 | 某一条结论是否有依据 | ASR、单条分析结果、规则命中和证据 | 高层项目价值叙事 |

## 已确认使用方式

- 高层可以随时登录查看，不是一次性汇报页面。
- 页面支持按月、按季度查看和比较数据。
- 当前建议默认展示“本月截至今日”，并提供“按月 / 按季度”切换。
- 页面核心使用规模和结果指标跟随所选月份或季度变化；历史累计成果仅能根据录音中曾出现的门店、顾问和分析结果反推。
- 月度默认与上月比较，季度默认与上季度比较；数据未完整结束时明确标注“截至当前”。

## 已确认使用口径

- 使用门店：所选月份或季度内，至少有 1 条归属该门店的录音完成 AI 分析。
- 使用销售顾问：所选月份或季度内，至少有 1 条归属该顾问的录音完成 AI 分析。
- 同一门店或顾问在周期内产生多条录音，仍只计数一次。
- 季度使用数按季度内去重对象计算，不能把三个月的使用数直接相加。
- 无法识别门店或顾问归属的录音不进入对应使用对象数，但仍可进入录音分析总量。

## 已确认推广口径

- 当前没有明确的应覆盖门店总数、应覆盖销售顾问总数或阶段推广目标。
- 页面不展示“推广目标完成率”“全国门店覆盖率”等没有可靠分母的指标。
- 系统没有独立门店/顾问主数据，只能从录音中反推实际使用对象。
- 页面展示周期使用门店数、使用顾问数，不展示已接入总数、活跃率或未使用对象。

## 已确认价值表达边界

- 当前没有上线前人工质检抽检比例、处理量、人力或工时基线。
- 页面不宣称“质检覆盖提升 X%”“效率提升 X%”“节省 X 人/小时”等无法验证的对比结论。
- 页面使用当前可验证事实证明价值：使用门店/顾问、完成 AI 分析的录音、纳入可见管理的销售过程、SOP 质检合格录音和风险录音。
- “从不可见到可见”是能力变化的定性表述，不包装成缺少基线的提升百分比。

## 已确认高层质检结果

- 不建立“需关注录音”综合指标。
- 话术缺陷属于常态化改进信息，录音中普遍可能出现，不作为高层异常录音的判定条件。
- 高层页面分别展示“SOP 质检合格录音数”和“风险录音数”，不把二者与话术缺陷合并。
- 两项核心结果卡统一展示“数量 + 比率 + 环比”。
- SOP 质检合格率的分母为所选周期内已完成且适用 SOP 质检的录音数。
- 风险录音率的分母为所选周期内已完成风险识别的录音数。
- 比率变化使用“百分点”表达，不写成容易混淆的百分比增长。
- 当前月份或季度未结束时，数量环比使用同期进度对比，例如本月 1—22 日对比上月 1—22 日；完整周期对比上一完整周期。
- 话术优势、话术缺陷及具体规则明细由厂端、门店和销售看板承接。
