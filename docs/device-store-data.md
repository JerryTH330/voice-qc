## 字段映射

| 页面字段 | Excel 字段 | 处理 |
| --- | --- | --- |
| 品牌 | company_name | 使用埃安/传祺原值 |
| 店代码 | dealer_code | 保留文本及前导零 |
| 门店名称 | dealer_shortname | 原值 |
| 门店关联 ID | dealer_wid | 使用包含公司代码的 ID，避免跨品牌同店代码混淆 |
| 大区、战区 | area_name、war_area_name | 使用普通组织维度；不以 hyper_* 替代 |
| 省份、城市 | province_name、city_name | 缺失城市明确显示“未维护” |
| 巡回员 | patrolman_name、patrolman_code | 真实姓名及人员代码；缺代码且同品牌姓名只对应唯一代码时补用该代码，否则使用内部品牌/姓名键 |
| 治理员 | govern_member | 文件未提供人员 ID，内部使用品牌/姓名键 |

人员名称“无”“其他”“缺失”按未提供处理，表格显示“—”，不生成虚构人员。文件中人员 ID 不完整，同品牌同名且无代码的记录无法进一步区分，内部姓名键只用于本原型筛选，不代表已核实的人员身份。

## 与工牌演示数据的关系

本文件不含顾问、工牌 SN、设备状态或绑定关系。工牌明细保留原有 94 家门店、470 条演示工牌/顾问记录，仅按品牌与店代码补充真实门店及负责人信息；新增门店可用于筛选，没有现有演示工牌时返回空结果，不据此认定门店没有真实工牌或工牌未绑定。

真实门店目录独立保存在 `device-management/organization-data.js`，仅由设备管理页面加载。其他页面的共享演示目录未替换。原有门店下钻链接继续可用，新下钻链接附带品牌以消除店代码歧义。
