# 录音列表 AI 意向等级规则提示设计

## 目标

在录音列表顶部筛选项“AI意向等级”文字后增加一个问号图标。用户在桌面端把鼠标移到图标上时，显示 AI 意向等级评定规则；鼠标移开后隐藏。

## 交互与视觉

- 问号使用圆形轻量图标，紧跟在“AI意向等级”文字后，不改变后面的“全部 / 高 / 中 / 低 / 无”筛选按钮逻辑。
- 鼠标悬停问号时显示浮层，移开问号与浮层区域后隐藏。
- 为键盘用户保留聚焦显示能力：Tab 聚焦问号时显示，失焦后隐藏。
- 浮层定位在问号下方，使用白色背景、圆角、细描边与轻阴影。
- 本次只保证桌面端效果，不增加移动端点击交互或专门适配。

## 规则内容

浮层标题为“AI意向等级评定规则”，主体为两列表格：

| 等级 | 判定标准 |
| --- | --- |
| 高 | 近期购买、问具体配置价格、主动约试驾、询问提车时间 |
| 中 | 有需求但时间未定、对比阶段、需再考虑、已约定跟进 |
| 低 | 仅初步了解、无明确计划、被推销后简单应付 |
| 无 | 明确拒绝、无意向 |
| 无法判断 | ASR内容过短或杂乱，无法提取信息，无法判断 |

## 实现边界

- 只修改录音列表现有运行时模板和页面样式，不抽取新的全局提示组件。
- 不修改筛选状态、筛选结果、录音数据或其它页面。
- 浮层使用语义化按钮和 `role="tooltip"`，图标带清晰的辅助说明。

## 验证

- 自动化测试先验证问号按钮、完整规则文案、表格结构和悬停/聚焦样式尚不存在，再实现并验证通过。
- 运行 JavaScript 语法检查和相关测试。
- 在桌面浏览器中实际悬停问号，确认浮层出现、内容完整、没有遮挡筛选操作；移开后确认隐藏。
