# 浅色登录页替换设计说明

## 目标

用 `/Users/linxianxin/Downloads/login-design-light.html` 的视觉、文案、示例卡片、动态声波和响应式布局，完整替换当前静态 HTML 项目的登录页。原登录页的视觉和旧交互不再保留。

登录行为保持不变：

- 默认账号为 `admin`。
- 默认密码为 `admin`。
- 租户、账号和密码都必须填写。
- 账号或密码错误时，在对应输入框显示错误状态。
- 登录成功时显示加载状态，然后跳转到 `./factory-dashboard/index.html`。

## 文件组织

采用项目现有的 HTML/CSS/JS 分离结构：

- `index.html`：保留参考页的页面结构、文案、SVG 图标和示例卡片，表单节点使用与登录脚本一致的 ID。
- `login.css`：完整替换为参考页的浅色视觉样式，并补充错误状态、加载状态和辅助文字的样式。
- `login.js`：保留账号校验和成功跳转，移除仅适用于旧页面的 3D 倾斜、密码显隐等旧交互，并接入参考页的 Canvas 声波动画。

不使用 iframe，不依赖 Downloads 目录中的参考文件，不保留第二套登录页。

## 页面结构

页面分为四个主要部分：

1. 顶部品牌标识“AI质检平台”。
2. 左侧产品价值文案和三项能力介绍。
3. 中间两张 AI 质检结果示例卡片。
4. 右侧登录卡片，包含租户、账号、密码和登录按钮。

背景 Canvas 继续使用参考页的横向声波动画。当用户开启“减少动效”时，展示静态声波。

## 响应式规则

- 宽度小于 1240px 时，隐藏中间示例卡片。
- 宽度小于 860px 时，改为单列排列，登录卡片居中。
- 宽度小于 520px 时，隐藏次要说明和第三项能力，避免移动端过长。

## 表单与错误处理

- 租户默认显示“AI质检管理”，但仍可编辑。
- 账号和密码不预填真实值，只显示输入提示。
- 空值或错误凭据会标红对应输入框并显示明确的错误文案。
- 用户重新输入时，对应错误状态自动清除。
- 提交期间按钮进入加载状态，并避免重复提交。

## 测试与验收

实施采用测试先行：

1. 先新增登录页结构与行为合约测试，确认它在旧页面上按预期失败。
2. 替换 HTML、CSS 和 JS，直到新测试通过。
3. 运行全量测试、JavaScript 语法检查和 `git diff --check`。
4. 使用真实浏览器检查桌面端和窄屏布局，并验证错误登录和 `admin/admin` 成功跳转。

## 改动边界

只修改登录页相关文件和对应测试，不调整看板、线索、录音等其他业务页面，不引入后端鉴权。
