# 登录页最小字号设计

## 目标

登录页所有在 `login.css` 中明确设置且小于 `14px` 的字号，统一提升为 `14px`。

## 范围

- 包含说明文字、卡片标签、表单标签、错误提示、底部合规文字及使用文字字符绘制的勾叉标记。
- 保留原本等于或大于 `14px` 的字号。
- 不修改页面结构、间距、登录账号、校验逻辑和跳转逻辑。

## 实现方式

直接修改现有 `font-size` 声明，不增加全局覆盖规则。这样每个组件的最终字号明确，后续维护时不会被额外的优先级规则干扰。

## 验收标准

- `login.css` 不再包含数值小于 `14px` 的 `font-size` 声明。
- 登录页专项测试与项目全量测试通过。
- JavaScript 语法与 Git 差异格式检查通过。
