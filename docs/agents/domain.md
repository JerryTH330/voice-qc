# Domain Docs

Engineering skills should read the following files before exploring the codebase:

- `CONTEXT.md` at the repository root
- `docs/adr/` for architecture decisions

If these files do not exist, continue normally. They will be created later when domain decisions need to be recorded.

This is a single-context repository, so domain documentation uses:

- One root `CONTEXT.md`
- One root `docs/adr/` directory

When writing issue titles, specs, tests, or proposals, use the terminology defined in `CONTEXT.md`.
